# Book Download MCP v1.4.1

First independent installation package, based on upstream zlibrary-mcp v1.4.0.

- Configurable account pools with authentication/quota failover and short-lived sessions.
- Parallel multi-source discovery with quality/rating evidence and version recommendations.
- Confirmation before downloads, with MCP form selection or conversational fallback.
- Optional `libgen_mcp` 2.2.1 and `find_a_book` 1.7.1 backends, retaining source provenance.
- Validated identifiers, isolated staging, integrity checks, private diagnostics and bounded workers.
- Existing 13 MCP tools and the `zlibrary-mcp` command remain available.
- Publication security fixes update aiohttp, Brotli, certifi, filelock and Pillow.
- Python 3.11+ is now required by the patched image stack; installation selects Python 3.12.

## Installation

Requires Node.js 22+ and UV. The archive contains compiled JavaScript and Python
sources; UV sets up Python 3.12 and dependencies after npm installation.

```sh
npm install --global https://github.com/gjjisadog/book-download-mcp/releases/download/v1.4.1/book-download-mcp-1.4.1.tgz
uv sync --project "$(npm root --global)/@gjjisadog/zlibrary-mcp" --frozen --no-dev --python 3.12
```

See the attached `INSTALL.md` for Windows instructions, checksum verification
and MCP client setup. `SHA256SUMS` covers both the archive and installation guide.
The npm registry package is not published yet; the GitHub download installs the
same scoped package directly. Never place account credentials in the install directory.

## Availability

The portable archive supports macOS, Linux and Windows with the stated runtimes.
Optional backend binaries depend on upstream platform availability. External
catalogs and mirrors can be unavailable; configured healthy sources remain usable.
Missing ratings and actual file clarity are reported as unknown.
